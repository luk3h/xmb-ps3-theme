# XMB wave shader

`xmb-wave.frag.qsb` is the animated PS3 XMB wave used by the login screen, the lock screen and (via the
Shader Wallpaper plugin) the desktop. It's a compiled Qt 6 shader (`.qsb`).

**Source and credit:** https://www.shadertoy.com/view/fcf3Dn
